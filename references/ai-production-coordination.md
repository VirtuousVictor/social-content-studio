# AI Production Coordination

Use this stage when the user is preparing batches of generated shots, tracking versions, or resolving continuity failures. It plans production; it does not render media.

## Build the production map

For each shot record priority, dependencies, required references, target tool, status, version, acceptance criteria, known risks, and next action. Group shots by shared scene, character, location, product setup, or lighting when this improves continuity.

## Prepare and lock references

Track product, actor, wardrobe, location, prop, style, logo, and audio references. State which shots use each asset. Define identity anchors, allowed changes, forbidden drift, and approved source of truth.

## Manage generation versions

Use a predictable naming scheme that ties project, episode, shot, aspect ratio, version, and status together. Keep accepted versions distinct from candidates. Record why an output passed or failed.

## Regeneration decisions

For each failed output, classify the cause: wrong identity, product, action, camera, text, lighting, continuity, platform format, or safety. Change only what failed; keep approved elements fixed. Regenerate hero product, face, and hand-interaction shots with the strictest references.

## Handoff

Maintain a shot status table, asset checklist, continuity locks, acceptance/rejection notes, regeneration instruction, and downstream edit notes. A beautiful output does not pass if it breaks product truth or continuity.
